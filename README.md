# Maclean Messaging

**Maclean Messaging** is an open-source Android SMS, MMS, voice-message, and optional email client designed to function as a complete replacement for the stock Android messaging application.

## Features

- Standalone SMS and MMS when set as Android's default SMS app
- Send and receive SMS/MMS directly through the device and carrier
- Immediate outgoing message display
- Multi-SIM support
- MMS photos and file attachments
- Voice-message recording and playback
- Complete conversation history
- Unified conversation inbox
- Optional multi-account IMAP/SMTP email
- Email synchronization and notifications
- Message scheduling, drafts, and outbox
- Android sharing integration
- Reply directly from notifications
- Mark individual, selected, or entire conversations read/unread
- Message search, sorting, selection, and bulk management
- Attachment and media handling
- Spam scoring
- Backup support
- Customizable message and interface appearance
- Multiple fonts including sans, serif, monospace, condensed, cursive, calligraphy, and special styles
- Regular, bold, italic, and bold-italic text styles
- Custom message/card shapes and contour-aware text
- Configurable top or bottom conversation reply area
- Background processing and caching for faster conversation loading
- Android 15 support

## Standalone Messaging

Maclean Messaging does **not require Google Messages or another SMS application** for normal SMS/MMS operation once Android assigns it the default SMS role and the necessary permissions.

SMS and MMS use Android's telephony and carrier infrastructure, while optional email is handled separately through IMAP/SMTP.

## Privacy

Core SMS/MMS data is processed through the Android device and carrier infrastructure. Email functionality remains optional and dormant until an email account is configured.
